WINOME — Windows GNOME Shell

适用于 Microsoft Windows 的原生 Linux GNOME 桌面环境复刻，基于 C++17、GTK4 与 St CSS 引擎构建。

查看 GitHub 仓库与源码

项目介绍

WINOME 不是简单的桌面皮肤或主题包，而是一个由 Windows 原生 API（DWM、WinRT、WASAPI、COM 虚拟桌面接口）驱动的完整桌面 Shell 体验。它接管原生任务栏与系统托盘，为 Windows 10/11 带来原汁原味的 GNOME 40+ 交互逻辑。

核心特性

  • Activities 全屏概览：单按 Win 键或触发左上角热角呼出窗口选择器，双击 Win 键进入分页应用网格，支持拖拽窗口跨虚拟桌面管理。
  • 置顶状态栏与快速设置：复刻 GNOME 顶部面板、双栏日期与通知中心、SMTC 媒体控制，以及蓝牙、Wi-Fi、亮度与音量快速调节抽屉。
  • 进程外插件与开发者控制台：内置进程隔离的 JSON 插件宿主机与 Alt+F2 / Looking Glass 实时样式调试台。
  • 高可靠安全守护：配备独立看门狗进程与 winome.exe --restore 一键还原机制，确保任何情况下均可快速恢复 Windows 原生任务栏。

快速开始与系统要求

  • 系统要求：Windows 10 / Windows 11（推荐 Win11 22621 或 24H2+ 以获得完整虚拟桌面接口支持）。
  • 下载与构建：前往 GitHub Releases 获取自包含便携版压缩包，或通过 MSYS2 UCRT64 运行 ./build.sh release 从源码构建。
  • 运行提示：隐藏原生任务栏需以管理员权限运行 winome.exe。
