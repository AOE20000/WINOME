   - 根因包括：(1) `systray_debug_inspect_json()` 在 `server_thread_main()` 上同步初始化 UIA 并调用 `ensure_shell_tray_accessible_cloaked()` 与 `worker_main()` 并发争夺 `Shell_TrayWnd` 可见性/定位，同时对 `[Shell_TrayWnd, TrayNotifyWnd, DesktopWindowContentBridge]` 重复执行无超时的 `FindAll(TreeScope_Descendants, TrueCondition)`，触发 UIA 默认 `20,000ms` COM `TransactionTimeout` 级联超时；(2) `worker_main()` 为单线程串行队列，弹窗 `on_tray_popover_map()` 每次触发 `force=true` 全量探测且周期扫描无图标缓存、重复枚举 `NotifyIconSettings` + `SHGetFileInfoW`，将右键动作长期排队在扫描之后，同时溢出区图标未按 `TraySurface` 路由而先浪费秒级时间扫描 `Shell_TrayWnd`，右键后 `Shell_TrayWnd` 又保持 cloak 并挂起 keeper `8000ms`。
2. **修复要点（`systray.{h,cpp}`、`shell-panel.{h,cpp}`、`ctl/winome-ctl.cpp`、`tests/test-main.cpp`）**：
   - 接入 `IUIAutomation2` 超时控制（`ConnectionTimeout=800ms`、`TransactionTimeout=1500ms`）与 `IUIAutomationCacheRequest`（`FindAllBuildCache` 批量取 `Name`/`AutomationId`/`ClassName`），`collect_uia_target_hwnds()` 在 Win11 存在 `DesktopWindowContentBridge` 时仅扫描 XAML 桥接 HWND（避免遍历任务栏按钮与三重扫描），并按 `entry.id` 与标题双重缓存图标（未命中 60s 冷却）；
   - 将 `systray.cpp` 拆分为 `action_worker`（高优先点击/右键与溢出切换）与 `scan_worker`（周期刷新且在 `action_in_flight` 期间让路），由 `shell_tray_mu` 串行保护 `Shell_TrayWnd` 临时探针；为 `TrayIconEntry` 增加 `TraySurface` 来源标记，溢出项直达溢出窗而不再盲扫 `Shell_TrayWnd`，并为每次动作输出 `[systray] action ... exec=...ms total=...ms` 诊断耗时；
   - `shell-panel.cpp` 托盘弹窗点击/右键改为 `winome_shell_panel_close_popovers_immediate()` 立即关闭弹窗并调用 `AllowSetForegroundWindow(ASFW_ANY)`，`on_tray_popover_map()` 仅触发轻量刷新（`force=false`）；右击 `Shell_TrayWnd` 后默认挂起从 `8000ms` 收紧至 `1500ms`（并仍受 `is_tray_overflow_open()` `#32768` 检测续期保护）；
   - `systray_debug_inspect_json()` 改为 `<10ms` 非阻塞瞬时返回（子窗口枚举配合 `SendMessageTimeoutW` `50ms`、返回缓存 `items`/`uia_probe` 与 `stats` 扫描/动作耗时），并在 `winome-ctl.cpp` 的 `query_pipe()` 增加 `PeekNamedPipe` 回复超时保护与输出刷新，杜绝命令行无限无输出挂起。
