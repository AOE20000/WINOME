# 2026-11-16：后 Phase 11 UI 对齐、应用网格性能与三态打断总结

本日志记录自 Phase 11（`af42925`）至应用网格重做完成（`cbd4360`）之间的核心修复与架构演进，并将相关结论同步至架构与主题文档。

## 1. 图标资源内置与 Quick Settings 居中展开

- **内置图标体系（`b6c5ef5`）**：将 12 个上游 GNOME symbolic SVG 图标及 `calendar-today.svg`、`workspace-placeholder.svg` 打入 [winome.gresource.xml](../../WINOME/src/theme/winome.gresource.xml)，消除系统环境缺少 Adwaita 图标主题导致的缺图问题。
- **Quick Settings 与二级抽屉（`36a5d98`、`ad1ef42`）**：
  - 电源二级菜单新增 `Quit WINOME` 安全退出入口；
  - 将 `QuickToggleMenu` 内联抽屉改造为两阶段居中展开/淡入过渡，消除从顶部整块滑落的生硬观感；
  - Wi-Fi 加密网络接入升级为对齐 `.modal-dialog` 的模态密码弹窗；`SettingsWindow` 切换为深色 Adwaita 样式并统一字体注入。

## 2. 顶栏、通知中心与概览视觉修缮

- **顶栏与通知（`0e511a4`、`46eb566`）**：修复时钟高亮指示器、日历今日圆点（`calendar-today.svg`）以及通知列表空状态图标与折叠动画对齐上游节点树。
- **概览 Chrome 与样式穿透（`1954315`、`95296ef`）**：修复悬停标题在 DWM 缩略图上的遮挡与省略号裁切，补全 `APP_GRID`、右键弹出菜单及滚动条的 GTK4 CSS 规则并通过 `tests/test-css-converter.py` 回归保护；全套上游 St CSS 属性到达转换后 GTK4 样式表数量从 `40/83` 提升至 `46/83`。

## 3. UWP 索引、高清图标、GObject 生命周期与双 Win 进阶

- **GObject C++ Placement-Init 修复（`7302f6b`）**：定位并修复 `AppGrid` 与 `Dash` 自定义 `GObject` 实例内嵌 C++ 容器成员（`std::vector` / `std::string`）因 `g_object_new` 零初始化导致的析构崩溃——全部非平凡成员改用 `*_init()` placement `new` 与 `*_finalize()` 显式析构。
- **UWP 索引与三线性高清缩放（`06a8a25`、`cbd4360`）**：
  - `app-index.cpp` 补充 `FOLDERID_AppsFolder`（`PKEY_AppUserModel_ID`）枚举，统一覆盖传统 `.lnk` 与 Store/UWP 应用；
  - 图标解码管线依次回退 `IShellItemImageFactory` → `SHIL_JUMBO` → `PrivateExtractIconsW` → `SHGetFileInfoW`，LRU 缓存上限扩充至 `1024`，通过后台线程解码 `RawDecodedIcon` + 主线程 `WinomeAppIcon`（`GSK_SCALING_FILTER_TRILINEAR`）避免大尺寸图标低清模糊与主线程卡顿。
- **三态统一过渡与 550ms 双击进阶（`cbd4360`）**：
  - `overview.cpp` 引入三态机 `ControlsState::{HIDDEN, WINDOW_PICKER, APP_GRID}` 及结构复用的 `app_grid_prewarm()` 预热路径；
  - `overview-trigger.cpp` 实现 `550ms` 内双击裸 `Win` 键无缝打断 `WINDOW_PICKER` 进入 `APP_GRID`，彻底复刻 GNOME 概览按压手感。

## 4. 长期规划 Stage 1（Shell 闭环）与 Stage 2（事件化与性能稳定性治理）

- **Stage 1：Shell 核心功能闭环与可控接口**
  - **双向 Named Pipe IPC**（`src/shell-ipc.{h,cpp}`、`main.cpp` `--status`）：提供 `\\.\pipe\WINOME_Shell_IPC` JSON 请求/响应总线，覆盖 `ping`、`status`（含版本/工作区/启动耗时/进程遥测/动画帧统计/子系统健康状态）、`overview.*`、`desktop.*`、`settings.open`、`config.*`、`notify`、`quit`。
  - **EndSession 60 秒倒计时确认弹窗**（`src/end-session-dialog.{h,cpp}`、`quick-settings.cpp`）：在执行 Restart / Power Off / Log Out 前弹出 GNOME `.modal-dialog` 60 秒确认弹窗（受 `config.json` `end_session_confirm` 开关控制，`Suspend` 与 `Quit WINOME` 保持直出）。
  - **GNOME 工作区快捷键与同步**（`src/overview-trigger.cpp`）：新增持久化 `HotkeyWorker` 线程异步处理 `Win+PageUp/PageDown`（切换工作区）与 `Win+Shift+PageUp/PageDown`（移动活动窗口并跟随），并在 `Win+Ctrl+Left/Right/D/F4` 触发 `vd::notify_change_hint_async()`。
  - **可选 DWM 窗口外观统一**（`src/window-theming.{h,cpp}`）：默认关闭（`unify_dark_titlebars` / `unify_rounded_corners`），启用时经 `SetWinEventHook` + `should_apply_dwm_theming_to_hwnd_info()` 零注入为外部普通应用窗口请求 DWM 暗色标题栏（属性 20）与 Win11 圆角（属性 33），禁用时干净恢复触摸过的窗口。
  - **Settings 扩展与 Diagnostics 页**（`src/settings-window.{h,cpp}`）：新增可选外观统一开关、`end_session_confirm` 开关、快捷键一览及按需刷新的 `Diagnostics` 标签页（支持 `open_settings_window_page()`）。

- **Stage 2：事件驱动重构、内存/启动治理与熔断隔离**
  - **消除冗余轮询**：
    - `hot-corner.cpp` 由 `100ms` 定时器迁移至独立线程 `WH_MOUSE_LL` 钩子，配置关闭或全屏隐藏面板（`hot_corner_set_suppressed(true)`）时自动摘除钩子，零空闲唤醒；
    - `virtual-desktop.cpp` 新增集中式 `add_change_listener()` / `cached_snapshot()` / `notify_change_hint_async()`（`EVENT_SYSTEM_DESKTOPSWITCH` + 热键提示 + 单一共享 `1.5s` 安全校对器），移除 `overview.cpp`、`shell-panel.cpp` 与 `ws-osd.cpp` 的各自轮询定时器；
    - `fullscreen-watcher.cpp` 补充 `EVENT_SYSTEM_MINIMIZEEND`，`monitor-manager.cpp` 补充 `SPI_SETWORKAREA` (`on_workarea_changed`)，将 `maintenance_tick` 放宽至 `10000ms`；
    - `notifications.cpp` 用单一可 join 的 `NotifWorker` 线程与 `2s`/`6s` 自适应周期取代每 `2s` `.detach()` 与悬空动作线程。
  - **启动耗时、纹理内存与异步生命周期治理**：
    - `fonts.cpp` 采用隔离 `FcConfigCreate()` 实例 + 精选 CJK/Emoji 回退链（测试进程 `winome-tests` 测得 `57.8ms`–`58.3ms`，主宿主运行场景实测 `1226.1ms`）；
    - `app-index.cpp` 与 `overview.cpp` 引入 `app_icon_cache_trim(256)` + `shrink_to_fit()` 15s 闲置释放、壁纸按目标显示器尺寸缩放解码（`gdk_pixbuf_new_from_file_at_scale` + `gdk_memory_texture_new`）、纯淡入跳过 `gtk_fixed_move` 重排与 `FrameTimeTracker(20000)` 帧耗时监控；
    - 修复 `virtual-desktop.cpp` 队列任务（`std::shared_ptr<Job>`）与 `winrt-bridge.cpp` 8s 超时任务的栈引用悬空 UAF，并为 `UserNotificationListener` 访问拒绝增加 `60s` 冷却。
  - **遥测、熔断器与全量验证**：
    - `perf-metrics.{h,cpp}` 实现 `StartupTimings`、`ProcessTelemetry`、`FrameTimeTracker` 与 `SubsystemId` 熔断注册表，已接入 `VirtualDesktop`、`SysTray`、`WinRtBluetooth`、`WinRtSmtc`、`WinRtNotifications`、`Brightness`、`Wlan`、`Fonts`、`IpcServer`；
    - 扩充 `WINOME/tests/test-main.cpp` 覆盖热角命中、`EndSession` 文案、DWM 窗口过滤、IPC JSON 路由与 Named Pipe 实机回环、VD 槽位与缓存修剪；`test`（`debugoptimized`）与 `release`（`LTO + NDEBUG`，产物 `winome.exe` 2.2M）双配置通过 `meson test`（`2/2 OK`）及 CSS/类名结构校验。
